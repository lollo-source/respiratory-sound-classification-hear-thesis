# Published BioCAS reference values

`published_biocas_task2_scores.csv` contains static organiser-published comparison values transcribed from the cited source paper/table metadata in each row. The source-PDF hashes distinguish the 2022 and 2023 publications.

These literature inputs are physically separate from thesis predictions and frozen thesis references. `reproduce_challenge.py` combines independently computed HeAR Fusion Scores with each named published subset. The resulting insertion position is a retrospective estimate within that incomplete subset, never an official rank or submission result.
